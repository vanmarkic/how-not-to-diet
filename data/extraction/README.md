# Extraction Data

This directory contains raw text files extracted from PDF sources during the data collection phase.

## Files

### Page Extractions
- `pages_120_200.txt` - Content from pages 120-200
- `pages_187_230.txt` - Content from pages 187-230
- `pages_201_270.txt` - Content from pages 201-270
- `pages_271_320_extract.txt` - Content from pages 271-320
- `pages_321_386_content.txt` - Content from pages 321-386
- `pdf_content.txt` - General PDF content

### Food Details
- `food_details.txt` - Detailed food information
- `food_details_new.txt` - Newly added food details
- `target_foods_extraction.txt` - Target foods extraction
- `target_foods_full.txt` - Complete target foods list

### Special Topics
- `ampk_fat_content.txt` - AMPK and fat-related content
- `sleep_foods_extract.txt` - Sleep-related foods
- `tweaks_content.txt` - The 21 tweaks content
- `final_section_analysis.txt` - Analysis of final sections

## Purpose

These files served as intermediate data during the extraction process. The processed and structured data can be found in:
- `/data/foods/` - Individual food JSON files
- `/data/recipes/` - Recipe JSON files

For detailed extraction reports and summaries, see `/docs/extraction/`.
