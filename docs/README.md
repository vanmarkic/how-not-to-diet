# Documentation

This directory contains all project documentation organized by category.

## Directory Structure

### `/docs/development/`
Development-related documentation including:
- API documentation and pagination strategies
- Data architecture and schema designs
- System summaries and technical decisions
- Test reports and results
- Development diary and progress tracking

**Key Files:**
- `API.md` - API documentation
- `data-schema.md` - Data structure documentation
- `DEVELOPMENT-DIARY.md` - Development progress log
- `SYSTEM_SUMMARY.md` - System architecture overview

### `/docs/extraction/`
Documentation related to data extraction from source materials:
- Extraction progress reports
- Page-by-page extraction summaries
- Food and recipe extraction reports
- Analysis of extracted content

**Key Files:**
- `EXTRACTION-PROGRESS.md` - Overall extraction progress
- `FINAL-EXTRACTION-SUMMARY.md` - Complete extraction summary
- Various page-specific extraction reports

### `/docs/guides/`
User-facing guides and reference documentation:
- Quick start guides
- SEO optimization guides
- Feature implementation guides
- User manuals and cheat sheets

**Key Files:**
- `QUICKSTART.md` - Quick start guide
- `USER_GUIDE.md` - Complete user guide
- `QUICK_REFERENCE.md` - Quick reference card
- `SEO-OPTIMIZATION.md` - SEO best practices
- `MENU-BUILDER-IMPLEMENTATION.md` - Menu builder feature guide

### `/docs/plans/`
Design documents and future planning:
- Feature design documents
- Architecture planning
- Implementation roadmaps
